# 🎵 BTS Album Sales Management System (Desktop App)

Aplikasi desktop manajemen penjualan album berbasis GUI yang dibuat menggunakan **Python** dan library **Flet**. Aplikasi ini dirancang untuk memudahkan pencatatan transaksi, pengelolaan stok/pemesanan album, dan pencatatan data pelanggan secara *real-time* (CRUD).

## ✨ Fitur Utama
- **Input Data Transaksi:** Meliputi Kode, Nama Album, Jumlah, Harga, Nama Pelanggan, dan Jenis Pembayaran.
- **Dynamic Dropdown Selection:** Pilihan instan untuk judul album dan opsi jenis pembayaran.
- **Operasi CRUD (Create, Read, Update, Delete):**
  - **Create:** Menambahkan data transaksi penjualan baru.
  - **Read:** Menampilkan daftar riwayat penjualan secara langsung di bawah form.
  - **Update:** Fitur edit data transaksi yang sudah tersimpan (ikon pensil).
  - **Delete:** Fitur hapus data transaksi (ikon tempat sampah).
- **Modern GUI:** Antarmuka bersih dan responsif dengan tema visual yang disesuaikan.
